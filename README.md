# WOLFWALKER Outdoor Website

Vue 3 + Vite + Tailwind CSS bilingual export website for outdoor equipment.

## Requirements

- Node.js 20.20.2
- npm 10+

## Commands

```bash
npm install
npm run dev
npm run build
```

Run `npm run check:visual` while the development server is available at `http://127.0.0.1:4173`. The check reuses the locally installed Chrome browser.

Product content is stored in `src/data/products.js`. Public photography and video are loaded from Unsplash and Pexels; replace those URLs with approved WOLFWALKER media before production deployment.
